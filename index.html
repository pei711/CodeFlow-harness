CodeFlow-harness

An Agent Harness for concurrent tasks and multi-turn conversations.

面向本地代码仓库的开源 Agent 运行时框架，支持多任务并发与长会话执行：让任务执行可重放、可评测，工具执行边界显式可控。会话级队列与并发上限保证同一会话内工具顺序、不同会话并行运行；上下文按预算治理与压缩；中断的任务可以从检查点恢复。

Python 3.12 Apache-2.0 Status · Alpha CLI · TUI · Gateway · 飞书
在 GitHub 查看 快速开始

核心能力

并发调度与多轮会话

基于 asyncio 的会话级队列 + 并发上限：同一对话内工具调用严格保序，不同会话并行执行；并发写任务用 Git Worktree 隔离工作目录与分支，跨进程锁避免定时任务重复领取。

分层上下文治理

每次模型调用前按预算组装前缀、记忆与历史；压力升高时先裁剪旧工具结果，再优先保留近期轮次，高压时将旧历史摘要到边界之后。

Checkpoint / Resume

任务状态持久化，中断后可从检查点恢复；覆盖进程崩溃、工作区漂移等 10 类恢复场景，恢复过程可验证。

Shell 沙箱

Shell 命令可运行在 Anthropic SRT 操作系统沙箱或 BoxLite MicroVM 中；隔离不可用时失败关闭（fail-closed），不降级执行。

混合记忆检索

已完成轮次自动生成本地摘要并持久化；新请求经语义向量与 BM25 双路召回（各 Top-3），RRF 融合后取 Top-3 相关记忆，无外部后端也可工作。

回归评测体系

自研 CodeFlowBench 之外，另以 SWE-bench Verified 50 任务做固定回归集，配合 LLM Judge 轨迹评分与 30 场景安全评测，让每次改动的效果可量化、可对比。

快速开始

1 · 克隆并安装（需要 Python 3.12；原生 TUI 需要 Node.js 22，安装器可代为准备）

git clone https://github.com/pei711/CodeFlow-harness.git
cd CodeFlow-harness
./install.sh

Windows PowerShell

git clone https://github.com/pei711/CodeFlow-harness.git
Set-Location CodeFlow-harness
.\install.ps1

2 · 在你的项目里完成初始化

cd /path/to/your-project
codeflow onboard --skip-memory

四步向导：LLM 凭据 → 显式关闭 Memory → 第一个真实 Turn → 验证结果。更多文档见仓库 docs/onboarding 目录。
