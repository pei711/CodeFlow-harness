# Public evaluation notes

The following notes describe benchmark results and their evidence boundaries:

- [Runtime scheduler experiments](runtime-scheduler-experiments.md)
- [CallEfficiency cost experiment](tokenwise-cost.md)
- [Tracing overhead](tracing-overhead.md)

Raw run artifacts, credentials, private environment details, and candidate indices are intentionally excluded. Each result applies only to the frozen workload and evidence boundary described in its own file.

Other files in this directory include exploratory results and follow-up notes. For example, [context management fixes](context-management-fix.md) describes a small exploratory retest, and the [claim audit](resume-claim-audit.md) records evidence gaps. These notes are not all certified benchmark claims; consult each file for its limitations.
