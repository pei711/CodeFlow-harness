## 4. 结论与口径对齐
- 在长会话和压缩降级条件下，简单 FIFO 截断因舍弃早期历史导致关键约束保留率跌至 66.7%；
- CodeFlow 分层治理通过受保护槽位锚定早期约束，将保留率提升至 100.0%（增益 +33.3%），并在修剪冗余工具结果后实现了 26.0% 的输入 Token 节省；
- 在 LLM Judge 评测维度下，治理组整体得分相比对照组呈现 +0.8 分的显著优势。
